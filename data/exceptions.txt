# Irregular and exception words. Format: written|category|note
# Blank lines and lines starting with # are skipped.
#
# WHY THIS FILE EXISTS: some words behave differently from what their spelling
# suggests. test/exceptions.test.js checks data/words.txt against the rules in
# lib/exceptions.js and FAILS when a word needs a line here and has none, so
# adding words to words.txt cannot silently introduce an exception. The test
# message says what to check. This file is also the source of truth for verb
# groups when conjugation is computed in code.
#
# WHEN YOU ADD WORDS to data/words.txt:
#   1. Run: npm test
#   2. For each problem it prints, look up how the word really behaves, then add
#      a line below (the category list is in lib/exceptions.js).
#   3. Verbs ending in る always need a group: ichidan or godan (or
#      irregular-verb for 来る and する). Verbs NOT ending in る are regular godan
#      and need no line. If unsure, check a dictionary: do not guess.
#   4. If a word shows up as "reading-differs", the dictionary used for sentence
#      readings picks a different reading than words.txt. Decide which is right.
#
# Categories: ichidan, godan, irregular-verb, special-te-form, honorific-verb,
#   na-adj-ends-in-i, irregular-i-adjective, attributive-na-form, reading-differs
